# The emoji legend is printed once by list and busy, not stored in index.md

## Context
`/fodo:list` printed 6–7 column index.md tables (ID, Date, Type, Size, Title, File) that wrap and break in Claude Code's table renderer; the request asked for one line per item, emojis for type and size, and a legend. Question: where does the legend go?

## Options considered
- Once at the end of list/busy output: no repetition when several tables are shown.
- In every index.md: GitHub readers see it, but /fodo:list would repeat it up to 3 times.
- Only in docs/todo/index.md: one GitHub entry point.

## Decision
The emoji legend is printed once by list and busy, not stored in index.md

## Consequences
index.md files on GitHub have no legend; the emojis must stay self-explanatory. Print the legend only when at least one item table with rows was shown.
