# The decisions table is compact too: ID, Status, linked Title

## Context
`/fodo:list` printed 6–7 column index.md tables (ID, Date, Type, Size, Title, File) that wrap and break in Claude Code's table renderer; the request asked for one line per item, emojis for type and size, and a legend. /fodo:decide also shows decisions/index.md verbatim, with Date, Status, Item, Title and File columns.

## Options considered
- `| ID | Status | Title |` with linked title: same fix, consistent.
- Leave the decisions table as it is: outside the request.

## Decision
The decisions table is compact too: ID, Status, linked Title

## Consequences
The decision's source item is no longer visible in the table; it stays in each decision's frontmatter (`item:`).
