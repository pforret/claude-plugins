# /fodo:commit estimates the semver bump from the diff and asks once before writing version files

## Context
Planning /fodo:commit: the request asks to estimate patch/minor/major and handle semver like setver.sh. Should the skill bump automatically, only suggest, or ask?

## Options considered
- Estimate, confirm, then bump: derive the level from the diff and the commit type, show the proposal and reason, confirm with one question that also offers no bump, write the version files in the same commit. Chosen.
- Suggest only: print the suggested `setver new <level>` like setver -O does. Safer, but not what was asked.
- Bump without asking: fastest, but a wrong minor/major guess lands in the tag history.

## Decision
/fodo:commit estimates the semver bump from the diff and asks once before writing version files

## Consequences
Every /fodo:commit run that changes code includes one AskUserQuestion. Bookkeeping-only commits propose 'none' so the question is quick. The skill never writes version files without that confirmation.
