# A repo counts as Bash when it has a .sh file in its root or bin/ and nothing else matched

## Context
Planning the project-type icons: Bash projects have no standard marker file like package.json.

## Options considered
- *.sh in root or bin/ (chosen): cheap, matches bashew-style repos.
- *.sh in root only: simpler, misses repos with scripts under bin/.
- Root, bin/ and scripts/: catches more, more false positives.

## Decision
A repo counts as Bash when it has a .sh file in its root or bin/ and nothing else matched

## Consequences
Bash is last in the priority order, so a repo with helper scripts and any other marker shows that other type.
