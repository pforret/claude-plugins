# The ICM investigation delivers a docs/research/icm.md page plus a decision record

## Context
Planning the ICM investigation: where should the findings live so they stay useful after the todo item is archived?

## Options considered
- Decision record plus a docs page `docs/research/icm.md`: the comparison table and run log survive and the mkdocs site (awesome-pages) publishes them automatically.
- Decision record only: lighter, but the comparison would be compressed into one ADR-style record.

## Decision
The ICM investigation delivers a docs/research/icm.md page plus a decision record

## Consequences
A new `docs/research/` folder exists for research write-ups. Later investigations of methodologies or tools go there too, each with a decision record pointing at the page.
