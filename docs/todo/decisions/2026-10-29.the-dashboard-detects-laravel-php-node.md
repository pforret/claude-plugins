# The dashboard detects Laravel, PHP, Node, Python, Java, Go, Rust, Ruby and Bash repos

## Context
Planning the project-type icons: which project types should the dashboard recognise from marker files in the repo root?

## Options considered
- Core set: Laravel (artisan), PHP (composer.json), Node (package.json), Python (pyproject.toml, requirements.txt, setup.py, Pipfile), Java (pom.xml, build.gradle[.kts]), Bash.
- + Go (go.mod), Rust (Cargo.toml), Ruby (Gemfile) (chosen together with the core set).
- + Docker (Dockerfile/compose.yaml): not chosen; usually next to another type.

## Decision
The dashboard detects Laravel, PHP, Node, Python, Java, Go, Rust, Ruby and Bash repos

## Consequences
Adding a type means one row in the detection table plus one SVG in dashboard/icons/. Checks stay root-only (plus bin/ for Bash) because they run on every page load.
