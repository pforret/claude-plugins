# busy decides on the legend from its captured output, since busy --all renders each repo in a subshell

## Context
The PRP said to print the legend once at the end of `busy` output when an item table with rows was shown. `busy_all` renders each registered repo inside a `( cd …; … )` subshell, so it cannot set a flag for its caller.

## Options considered
- A flag set by print_busy: does not survive the subshell in busy_all.
- Capture the output (`out=$(…)`) and look for the table header `| ID | T | S |`: what was done; one code path for single repo and --all.

## Decision
busy decides on the legend from its captured output, since busy --all renders each repo in a subshell

## Consequences
If the busy/plan table header text changes, update the `case "$out" in *"| ID | T | S |"*` check in busy_cmd too, or the legend disappears.
