# Type and size are shown as emojis: 🐞 🔧 ✨ for type, 🟢 🟡 🔴 ❔ for size

## Context
`/fodo:list` printed 6–7 column index.md tables (ID, Date, Type, Size, Title, File) that wrap and break in Claude Code's table renderer; the request asked for one line per item, emojis for type and size, and a legend. Question: which emojis?

## Options considered
- 🐞 🔧 ✨ + 🟢 🟡 🔴 ❔ (traffic light for effort).
- 🐛 ♻️ 🆕 + plain S/M/L letters: aligns, less colourful.
- 🐞 🔧 ✨ + 🐁 🐕 🐘 animals: playful, less obvious.

## Decision
Type and size are shown as emojis: 🐞 🔧 ✨ for type, 🟢 🟡 🔴 ❔ for size

## Consequences
Unknown types or sizes map to ❔. Keep the mapping in one helper so the legend, index.md and any future view agree.
