# fodo pick shows an fzf preview of the item file

## Context
With fzf available, the picker can show the item file next to the list to help choose.

## Options considered
- fzf `--preview` with the first lines of the item file: cheap, helps choose.
- Plain fzf list: simplest.

## Decision
fodo pick shows an fzf preview of the item file

## Consequences
Rows are tab-separated with the relative item path as the last, hidden field (`--with-nth`), used by `--preview`. The numbered fallback has no preview.
