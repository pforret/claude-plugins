# The index.md tables themselves use the compact format, one format for terminal, GitHub and MkDocs

## Context
`/fodo:list` printed 6–7 column index.md tables (ID, Date, Type, Size, Title, File) that wrap and break in Claude Code's table renderer; the request asked for one line per item, emojis for type and size, and a legend. Question: change index.md itself or only the terminal output?

## Options considered
- Change index.md via write_index(): one format everywhere; skills keep showing index.md verbatim.
- Terminal-only compact view, index.md unchanged: GitHub keeps Date/File, but two formats to maintain.

## Decision
The index.md tables themselves use the compact format, one format for terminal, GitHub and MkDocs

## Consequences
GitHub and MkDocs readers see the compact tables too. Anything that greps index.md rows (tests, hooks) must match the new `| ID | T | S | [title](file) |` shape.
