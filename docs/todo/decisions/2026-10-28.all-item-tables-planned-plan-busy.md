# All item tables (planned, plan, busy, someday, done, skipped) share the compact format

## Context
`/fodo:list` printed 6–7 column index.md tables (ID, Date, Type, Size, Title, File) that wrap and break in Claude Code's table renderer; the request asked for one line per item, emojis for type and size, and a legend. The request named /fodo:list; the same write_index() renders the someday, done and skipped tables.

## Options considered
- All item tables compact: one format, one code path.
- Only planned/plan/busy: smaller change, but done/skipped keep the wide format.

## Decision
All item tables (planned, plan, busy, someday, done, skipped) share the compact format

## Consequences
Done and skipped tables (the longest ones) lose their Date column; the date stays in the linked filename.
