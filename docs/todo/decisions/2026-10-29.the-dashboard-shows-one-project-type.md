# The dashboard shows one project-type icon per repo, the most specific

## Context
Planning the project-type icons on the dashboard: a repo often matches several types (a Laravel app has artisan, composer.json and package.json). How many icons per repo?

## Options considered
- Most specific only (chosen): one icon by priority Laravel > PHP > Node > Python > Java > Go > Rust > Ruby > Bash; calm headers.
- All matching types: more information, noisier cards and busy list.
- Framework + language (max two): middle ground, needs a framework/language split for every type.

## Decision
The dashboard shows one project-type icon per repo, the most specific

## Consequences
Detection is an ordered table in dashboard/index.php; the first match wins, so order matters (Laravel before PHP, PHP before Node). A polyglot repo shows only its top type.
