# /fodo:commit maps commit types to bumps like setver, with no bump for bookkeeping-only commits

## Context
Planning /fodo:commit: how is the bump level derived from a commit?

## Options considered
- setver's mapping (suggest_next_version_bump): `!` or BREAKING → major, feat → minor, fix and any other type → patch; plus 'none' when only docs/todo/**, docs/**/*.md or CHANGELOG.md changed. Chosen, so setver and fodo agree.
- Semantic analysis of the diff only: more accurate in theory, not reproducible.
- Always patch unless told otherwise: simple, but feat commits would never bump minor.

## Decision
/fodo:commit maps commit types to bumps like setver, with no bump for bookkeeping-only commits

## Consequences
The level is predictable from the subject prefix; the diff only adds the bookkeeping exception and a hint when no prefix is given. Changing the mapping means changing setver too.
