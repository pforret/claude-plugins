# fodo pick prints the Claude command when claude or a terminal is missing

## Context
`fodo pick` may run where `claude` is not on the PATH, or without a terminal (piped input, tests, scripts), where an interactive session cannot start.

## Options considered
- Print `Run in Claude Code: /fodo:<cmd> <id>` and exit 0: never fails after a valid choice; testable.
- Exit 1 with `claude not found`: stricter, but the choice is lost.

## Decision
fodo pick prints the Claude command when claude or a terminal is missing

## Consequences
The launch needs `command -v claude` plus a terminal on stdin and stdout; otherwise the last line is exactly `Run in Claude Code: /fodo:<cmd> <id>`. Tests rely on that line and on piped stdin never launching anything.
