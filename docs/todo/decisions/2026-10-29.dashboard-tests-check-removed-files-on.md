# Dashboard tests check removed files on disk, not by expecting a 404 from the dev server

## Context
The PRP for the project-type icons asked for a test that /laravel.svg returns 404 after the move to icons/. PHP's built-in server (php -S -t dashboard, no router, used by /fodo:web and the bats tests) serves index.php with 200 for any missing path.

## Options considered
- Spec: curl the old path and expect 404; impossible without adding a router to web.sh.
- Done: assert on the file system that dashboard/laravel.svg is gone and only icon.svg is left in the root.
- Not chosen: add a router script to web.sh that 404s unknown static paths; changes server behaviour for one test.

## Decision
Dashboard tests check removed files on disk, not by expecting a 404 from the dev server

## Consequences
Removed or moved dashboard assets are tested with file checks. Served assets can still be tested with curl for 200.
