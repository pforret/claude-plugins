# docs/publishing.md lists the dashboard's SVG files and is updated when icons move

## Context
The PRP for the project-type icons did not list docs/publishing.md, but its note on validator holds said the dashboard only uses icon.svg and laravel.svg.

## Options considered
- Spec: leave the doc alone; it would name a file that no longer exists there.
- Done: say the dashboard uses icon.svg and the SVGs in icons/.

## Decision
docs/publishing.md lists the dashboard's SVG files and is updated when icons move

## Consequences
When dashboard image assets move or change type, check docs/publishing.md: code must keep referencing SVGs only (PNGs hold the plugin validator).
