# Project-type icons come from Simple Icons (CC0), committed into the dashboard

## Context
Planning the project-type icons: the dashboard needs a set of recognisable SVG marks, and must make no external requests (tests/web.bats).

## Options considered
- Simple Icons, CC0 (chosen): recognisable brand marks, no attribution needed; fill colour must be added by hand.
- Hand-drawn badges: no license questions, uniform look, less recognisable.
- Devicon (MIT): colourful logos, needs a license notice.

## Decision
Project-type icons come from Simple Icons (CC0), committed into the dashboard

## Consequences
Icons are committed under plugins/fodo/dashboard/icons/<type>.svg, never linked from a CDN. Simple Icons has no Java mark, so Java uses openjdk. Dark marks (rust) need a dark-scheme CSS tweak.
