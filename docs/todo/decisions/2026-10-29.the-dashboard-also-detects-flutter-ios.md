# The dashboard also detects Flutter, iOS and Android app repos, ranked right after Laravel

## Context
While implementing the project-type icons, the user asked to also recognise iOS and Android app repos, and Flutter projects "even if they're in an app/ subfolder". Mobile repos also carry markers of other types (Flutter has ios/ and android/, React Native has package.json, Android has gradle files like Java).

## Options considered
- Rank Flutter > iOS > Android right after Laravel (chosen): the app type wins over the build-tool markers it contains.
- Rank them by language (Android as Java, React Native as Node): no new icons, but less informative.

## Decision
The dashboard also detects Flutter, iOS and Android app repos, ranked right after Laravel

## Consequences
Markers: Flutter = pubspec.yaml in the root or app/; iOS = *.xcodeproj / *.xcworkspace in the root or ios/; Android = AndroidManifest.xml in the root, app/src/main/ or android/app/src/main/. A pure Dart package (pubspec.yaml without Flutter) and a macOS-only Xcode project are labelled Flutter and iOS. A React Native app shows iOS (first match).
