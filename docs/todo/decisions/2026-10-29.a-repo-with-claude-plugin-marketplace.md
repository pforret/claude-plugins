# A repo with .claude-plugin/marketplace.json is a Claude marketplace project and outranks every other type

## Context
While implementing the project-type icons, the user asked that a repo with .claude-plugin/marketplace.json automatically count as a Claude marketplace project. Such repos usually also hold scripts or a PHP/Node app (this repo has *.sh and a PHP dashboard), so the type has to come first to be seen.

## Options considered
- First in the priority order (chosen): every marketplace repo shows the Claude icon (Simple Icons "claude", #D97757).
- After the language types: the marketplace would only show when nothing else matched, i.e. almost never.

## Decision
A repo with .claude-plugin/marketplace.json is a Claude marketplace project and outranks every other type

## Consequences
Only marketplace.json counts; a single-plugin repo (.claude-plugin/plugin.json only) is not recognised. Extends decisions/2026-10-29.the-dashboard-detects-laravel-php-node.md.
