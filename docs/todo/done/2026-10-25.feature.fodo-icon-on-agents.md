# Show fodo icon on agents page for /fodo prompts

## Request
when showing agents on http://fodo.test/agents, if the last prompt started with '/fodo:...' then show a fodo favicon next to the claudeplugintodo-4d name

## Analysis
The `/agents` page (`plugins/fodo/dashboard/index.php`) renders one row per Claude Code session via
`render_agent_row()`. The last prompt is only read for the selected session (`transcript_peek()`,
which parses the last 512 KB of `~/.claude/projects/*/<sessionId>.jsonl`). Transcripts store it as
`{"type":"last-prompt","lastPrompt":"/fodo:start 3",...}`, so slash commands keep their `/fodo:`
prefix. To flag every row we need a cheap per-session lookup: read the transcript tail and take
the last `last-prompt` line only (no full parse). The dashboard already ships `icon.svg` (the fodo
logo), so the marker is `<img src="icon.svg">` next to the session name.

## Impacted files
- `plugins/fodo/dashboard/index.php` — `last_prompt()` helper, pass a flag into `render_agent_row()`, render the icon
- `tests/web.bats` — fixture transcript with a `/fodo:` prompt → icon shown; other prompt → not shown

## Plan
1. [x] Add `last_prompt(string $projectsDir, string $sessionId): ?string` reading the transcript tail and returning the last `lastPrompt`.
2. [x] In the `/agents` loop, set `fodo => str_starts_with(ltrim(last_prompt), '/fodo:')` per row.
3. [x] `render_agent_row()`: when set, add `<img class="fodo-mark" src="icon.svg" alt="fodo" title="last prompt: …" width="16" height="16">` after the name.
4. [x] Bats test.

## Acceptance criteria
- On `/agents`, a session whose last prompt starts with `/fodo:` shows the fodo icon next to its name; others don't.
- Sessions without a transcript still render.
- `bats tests/web.bats` passes.
