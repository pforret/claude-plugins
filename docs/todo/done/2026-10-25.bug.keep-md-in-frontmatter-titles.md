# Keep .md in frontmatter titles in fodo.sh list

## Request
Bug in `fodo.sh` at line 163: it cuts `.md` off every title in the list, not just titles taken from filenames, so "Fix typo in README.md" lists as "…in README". (Follow-up from the two-minute-rule item's Discoveries.)

## Analysis
In `plugins/fodo/scripts/fodo.sh:163` the table builder does
`title=$(field "$f" title); [ -n "$title" ] || title=${base#*.*.}; title=${title%.md}`.
The `%.md` strip is meant for the filename fallback (`<slug>.md`), but it runs after both branches, so a frontmatter
title that ends in ".md" loses it. Seen in the headless `/fodo:add` runs: `title: Fix typo "wrold" in README.md`
listed as `Fix typo "wrold" in README`. The dashboard is not affected: `items()` in `plugins/fodo/dashboard/index.php`
uses the frontmatter title as-is and strips the extension only in its fallback.
The personal skill `~/.claude/skills/todo/todo.sh:136` has the same line. Fixing it there is outside this repo.

## Impacted files
- `plugins/fodo/scripts/fodo.sh`: apply `%.md` only in the filename fallback
- `tests/fodo.bats`: regression test using the existing `item <dir> <filename> [title]` helper (line 21)

## Plan
1. Change line 163 to `title=$(field "$f" title); [ -n "$title" ] || { title=${base#*.*.}; title=${title%.md}; }`.
2. Add a bats test: an item with `title: Fix typo in README.md` lists with the `.md` intact, and an item without a title
   still lists its slug without `.md`.
3. `bats tests/` and `shellcheck plugins/fodo/scripts/*.sh`.

## Acceptance criteria
- `fodo.sh list` shows a frontmatter title ending in ".md" unchanged
- Items without a `title:` still show the slug without ".md"
- `bats tests/` and `shellcheck plugins/fodo/scripts/*.sh` pass

## Notes
- [x] 1. `plugins/fodo/scripts/fodo.sh:163`: `%.md` now only applies inside the filename fallback (`{ …; }` group)
- [x] 2. New test "list keeps .md in a frontmatter title, strips it from the filename fallback" in `tests/fodo.bats`.
  With the fix stashed it fails (`not ok 4`); with the fix it passes.
- [x] 3. `bats tests/` → 55/55, exit 0 · `shellcheck plugins/fodo/scripts/*.sh` → clean
- Discovery: `fodo.sh list` only prints the stored `index.md`; it does not rebuild it. The test needs `reindex` first.
  The first version of the test failed for that reason, not because of the fix.
- Discovery: the local bats is 0.4.0, which has no `-f` filter, so single tests can't be selected.
- Discovery: the `item()` helper in `tests/fodo.bats` uses the filename as the title when none is given, so those
  titles end in ".md". No existing assertion depended on the old stripping.

## Result

### Verification
- Frontmatter title ending in ".md" listed unchanged: new bats test "list keeps .md in a frontmatter title, strips it
  from the filename fallback" asserts `| Fix typo in README.md |` → ok (and fails with the fix stashed: `not ok 4`)
- Item without `title:` still lists its slug without ".md": same test asserts `| no-title |` → ok
- `bats tests/` → 55/55 ok, exit 0
- `shellcheck plugins/fodo/scripts/*.sh` → clean
- `grep -n 'title%.md' plugins/fodo/scripts/fodo.sh` → only inside the fallback group at line 163

### Deviations from the spec
- The test calls `fodo.sh reindex` before `list`, because `list` only prints the stored `index.md`.

### Discoveries
- `fodo.sh list` doesn't rebuild indexes. Items written by hand show up only after `reindex` or a move.
- The local bats is 0.4.0 (no `-f` filter for running a single test).
- The same bug is still in the personal skill at `~/.claude/skills/todo/todo.sh:136` (outside this repo, not changed).

### Changes
- plugins/fodo/scripts/fodo.sh: line 163, `.md` strip limited to the filename fallback
- tests/fodo.bats: one new regression test
