# Recognise .claude-plugin/plugin.json as a Claude plugin repo

## Request
recognize .claude-plugin/plugin.json as a Claude plugin repo

## Analysis
Extends the project-type icons (done item `done/2026-10-28.feature.dashboard-project-type-icons.md`). Today only
`.claude-plugin/marketplace.json` is recognised (type `claude`, label "Claude marketplace", first row of
`PROJECT_TYPES` in `plugins/fodo/dashboard/index.php` ~line 950). A repo that is a single plugin, with only
`.claude-plugin/plugin.json` in its root, gets whatever its files say (often Bash, Node or nothing).

A new row right after `claude`, e.g. `'claude-plugin' => ['Claude plugin', ['.claude-plugin/plugin.json']]`, so:
- a marketplace repo still shows "Claude marketplace" (its plugins keep their `plugin.json` under `plugins/<name>/`, not
  in the root, so they never match; this repo is an example);
- a plugin repo shows "Claude plugin" ahead of Laravel/PHP/Node/Bash.

`render_ptype()` builds the icon path from the type key (`icons/<type>.svg`), so the new type needs its own file;
the simplest is a copy of `icons/claude.svg` named `icons/claude-plugin.svg` (same mark, the title tells them apart).

Open questions (small): same icon for both, or a variant for plugins? Default: same mark, as a copy.

## Impacted files
- `plugins/fodo/dashboard/index.php` — one `PROJECT_TYPES` row after `claude`
- `plugins/fodo/dashboard/icons/claude-plugin.svg` — copy of `claude.svg`
- `plugins/fodo/dashboard/faq.md` — add "Claude plugin (`.claude-plugin/plugin.json`)" to the type list in "What is the small icon next to a repo name?"
- `tests/web.bats` — a `plugin` repo in `ptype_fixture` (plugin.json plus a `*.sh`), an assertion, and `claude-plugin` in the served-icons loop

## Plan
1. Copy `icons/claude.svg` to `icons/claude-plugin.svg`.
2. Add the `claude-plugin` row to `PROJECT_TYPES` directly after `claude`.
3. Extend the FAQ type list and the "first match" sentence.
4. Extend `ptype_fixture` and the two project-type tests in `tests/web.bats`.
5. `php -l plugins/fodo/dashboard/index.php`, `bats tests/web.bats`, `bats tests/`.

## Acceptance criteria
- A repo with only `.claude-plugin/plugin.json` (plus e.g. a `.sh` file) shows `icons/claude-plugin.svg` with alt "Claude plugin" and title "Claude plugin project (.claude-plugin/plugin.json found)".
- A repo with `.claude-plugin/marketplace.json` still shows "Claude marketplace"; this repo still does on the real dashboard.
- `icons/claude-plugin.svg` is served (200) and valid SVG.
- FAQ lists the new type; `bats tests/` passes.
