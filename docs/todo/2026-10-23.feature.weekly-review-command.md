# Add /fodo:review weekly review command

## Request
GTD-inspired: `/fodo:review` (the weekly review). Claude goes through the items and flags planned items
older than N days, busy items whose files haven't changed in git for a while, and PRPs whose code has
moved on since they were written. For each one it asks you to keep, re-plan, park, skip or start.

## Analysis
GTD's "Review" step has no counterpart in fodo; items go stale silently. Claude can check each item
against the actual code (git log on the `files:` frontmatter), which a plain todo app cannot.
Depends on the someday item for the "park" action (fall back to keep/skip if that is not built yet).
Open questions: default staleness thresholds (e.g. planned > 30 days, busy > 7 days without commits
to its files), whether to record a `reviewed:` date in frontmatter, and whether to remember the last
review date per repo (e.g. `docs/todo/.last_review`) so the dashboard can nudge.

## Impacted files
- `plugins/fodo/skills/review/SKILL.md`: new skill with the review walk-through
- `plugins/fodo/scripts/todo.sh`: optional `stale` subcommand printing age / last-file-change per item
- `plugins/fodo/reference/conventions.md`: document the review and any new frontmatter field
- `plugins/fodo/README.md`: command table
- `tests/todo.bats`: tests for any new helper subcommand

## Plan
1. Decide thresholds and the per-item actions (keep, re-plan, park, skip, start).
2. Add a `todo.sh stale` helper that lists items with created/moved dates and the last git commit
   touching their `files:`.
3. Write the review skill: run the helper, group findings, ask per item, execute moves via `todo.sh`.
4. For plan items, compare the PRP's referenced files against commits since the PRP was written.
5. Document in README and conventions; add bats tests.

## Acceptance criteria
- `/fodo:review` lists stale planned, busy and plan items with the reason each was flagged
- Each flagged item can be kept, re-planned, parked, skipped or started from within the review
- Moves go through `todo.sh` and indexes are rebuilt
- README command table lists `/fodo:review`; bats tests pass
